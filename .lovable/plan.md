

## Renomear "Contatos" para "Usuários" no menu

Alterar o label do item de menu no `AppSidebar.tsx` de "Contatos" para "Usuários", e atualizar a rota correspondente de `/app/contatos` para `/app/usuarios`. Também atualizar o título da página `Contatos.tsx` e a rota no `App.tsx`.

### Arquivos a editar

1. **`src/components/AppSidebar.tsx`** — Renomear label "Contatos" → "Usuários", path `/app/contatos` → `/app/usuarios`
2. **`src/App.tsx`** — Atualizar rota de `/app/contatos` para `/app/usuarios`
3. **`src/pages/app/Contatos.tsx`** — Atualizar título h1 de "Contatos" para "Usuários" e texto descritivo
